# CLAUDE.md — Engineering OS

This project uses Engineering OS. Follow `ENGINEERING_OS.md` and the `eos` CLI.

Default behavior:

- Run `eos status` / `eos next` at the start of substantive work
- Do not implement before required artifacts and gates allow it
- Never invent backend contracts

Slash commands:

- `/eos-status`
- `/eos-next`
- `/eos-start`

Intelligence helpers: `eos intel scan|graphs|impact|reuse|change-impact`, `eos context`, `eos knowledge search`.
