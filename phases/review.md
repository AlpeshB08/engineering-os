# Phase: Review

## Goal

Review the change (or diff) against Engineering OS standards and produce review notes.

## Inputs

- Diff / changed files
- Standards and checklists
- Artifacts from the run (if any)

## Steps

1. Self-review implementation against approved Feature Contract and Implementation Plan.
2. Check reuse, planning, verification, and change-control compliance.
3. Fill self-review table in `review-notes.md`.
4. Note must-fix / should-fix / nice-to-have findings.
5. Fill verdict in `review-notes.md`.

## Exit criteria

- [ ] `review-notes` complete with verdict

## Stop conditions

- Insufficient diff context — ask human for range/PR
