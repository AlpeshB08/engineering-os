# Phase: Report

## Goal

Produce the structured report artifact for audit or code-review workflows.

## Inputs

- Audit or review findings

## Steps

1. Write `audit-report.md` or `report.md` / finalize `review-notes.md` per workflow required artifacts.
2. Include prioritized recommendations.
3. Keep claims evidence-based.

## Exit criteria

- [ ] Required report artifact complete

## Stop conditions

- Missing evidence for a claimed finding — remove or mark unknown
