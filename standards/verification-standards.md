# Verification Standards

## Rules

1. Verification is mandatory before Delivery Preparation is valid.
2. Select checks from detected capabilities; skip only with written evidence.
3. Capture command results or manual outcomes in `verification-evidence.md`.
4. Acceptance criteria from the Feature Contract must be addressed.
5. Use QA and regression checklists appropriate to the archetype.
6. Never claim “tests passed” without recording what was run.
