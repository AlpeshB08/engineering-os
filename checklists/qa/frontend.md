# QA Checklist — Frontend

- [ ] Happy path UI works for acceptance criteria
- [ ] Loading, empty, and error states handled consistently with existing patterns
- [ ] Forms validate and show errors via existing form components
- [ ] Navigation / routing updated if new pages were added
- [ ] Responsive behavior checked at mobile and desktop widths used by the product
- [ ] No hardcoded secrets or env values in client code
- [ ] Reused design tokens / shared components (no one-off visual system)
- [ ] Console free of new errors on primary flows
