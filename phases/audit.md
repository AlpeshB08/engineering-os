# Phase: Audit

## Goal

Perform a read-only audit of architecture, capabilities, risks, and reuse opportunities.

## Inputs

- Repository Profile
- Discovery notes

## Steps

1. Inspect structure, conventions, and tooling evidence.
2. Identify risks and capability gaps.
3. Draft findings for the audit report (no application code changes).

## Exit criteria

- [ ] Findings ready for `audit-report` / report phase
- [ ] No non-documentation application code modified

## Stop conditions

- None (read-only)
