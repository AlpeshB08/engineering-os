# Playbook: No backend access

- **ID:** no-backend-access
- **Type:** playbooks
- **Tags:** engineering-os
- **Summary:** See body.


1. Set Backend availability to `no` or `unknown` in Repository Profile / Backend Dependency.
2. List required contracts as missing/unknown with evidence.
3. Agree stub/mock strategy with the human — do not invent production APIs.
4. Limit implementation to client-safe work or stop for follow-up.
5. Record decisions in the Decision Log.
